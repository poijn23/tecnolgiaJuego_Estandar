\subsection{Campos Privados}

\subsubsection{Regla: prefijo de guion bajo}

\textbf{Regla:} Todo campo \texttt{private} o \texttt{internal} no constante, sea de instancia o estático, se escribe en \texttt{camelCase} con guion bajo inicial (\texttt{\_campo}). No se emplea el prefijo especial \texttt{s\_} para campos estáticos.

\textbf{Descripción:} Facilita el análisis automático del código (autocompletado, analizadores de estilo) y es la convención de nombrado oficial del equipo de .NET Runtime (Microsoft, 2025c).

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class TurnManager
{
    private readonly List<Player> _players;
    private int _currentPlayerIndex;

    public TurnManager(List<Player> players)
    {
        _players = players;
        _currentPlayerIndex = 0;
    }
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class TurnManager
{
    private readonly List<Player> players;
    private int currentPlayerIndex;

    public TurnManager(List<Player> players)
    {
        this.players = players;
        currentPlayerIndex = 0;
    }
}
\end{lstlisting}

\subsubsection{Regla: misma convención para campos estáticos}

\textbf{Regla:} Un campo \texttt{static} privado o interno conserva el prefijo de guion bajo y no agrega marcadores relacionados con su almacenamiento.

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class GameSessionRegistry
{
    private static readonly List<Player> _connectedPlayers = new();
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class GameSessionRegistry
{
    private static readonly List<Player> s_connectedPlayers = new();
}
\end{lstlisting}

\subsubsection{Regla: momento de inicialización de un campo}

\textbf{Regla:} Todo campo queda inicializado antes de que la instancia esté disponible para su uso. Un campo cuyo valor no depende de los parámetros del constructor se inicializa en línea, en su propia declaración. Un campo cuyo valor depende de un parámetro del constructor o de lógica de construcción se inicializa en el cuerpo del constructor. Prohibido dejar un campo de referencia no anulable sin asignar en el constructor para que un método posterior lo asigne por primera vez (McConnell, 2004).

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class GameSession
{
    private readonly Guid _sessionId = Guid.NewGuid();
    private readonly List<Player> _players;

    public GameSession(List<Player> players)
    {
        _players = players;
    }
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class GameSession
{
    private List<Player> _players;

    public GameSession(List<Player> players)
    {
    }

    public void Configure(List<Player> players)
    {
        _players = players;
    }
}
\end{lstlisting}
