\subsection{A Nivel de Clase}

\subsubsection{Regla: etiqueta \texttt{summary} en servicios públicos}

\textbf{Regla:} La documentación XML se agrega únicamente en clases públicas de la capa de servicios, con una etiqueta \texttt{<summary>} redactada en inglés. Prohibido agregar documentación XML a clases de dominio, infraestructura, interfaz gráfica o pruebas, salvo que expongan una API pública externa al proyecto (Microsoft, 2026c).

\textbf{Ejemplo correcto:} \texttt{SaveGameService} incluye un \texttt{summary} en inglés que indica: ``Saves and restores game sessions.''

\textbf{Ejemplo incorrecto:} \texttt{SaveGameService} carece de \texttt{summary}, o lo redacta en español. También es incorrecto agregar documentación XML rutinaria a cada clase fuera de la capa de servicios.
