\subsection{Diseño de Excepciones Propias}

\subsubsection{Regla: constructores de una excepción propia}

\textbf{Regla:} Una excepción propia hereda de \texttt{Exception}, se declara \texttt{sealed}, termina en \texttt{Exception} (Sección 2.14.1), fija su mensaje en inglés dentro del constructor y expone sus datos mediante propiedades de solo lectura. Si no lleva datos, declara los tres constructores estándar que exige la regla de análisis \texttt{CA1032} (Microsoft, 2016b). Si lleva datos obligatorios, declara solo los constructores que los reciben.

\textbf{Descripción:} Un constructor sin parámetros dejaría una excepción con datos sin asignar, lo que contradice la Sección 2.6.3. Como la clase es \texttt{sealed}, ninguna clase derivada necesita los constructores restantes.

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class TileOccupiedException : Exception
{
    public TileOccupiedException(Tile tile)
        : base($"The tile is already occupied. Row={tile.Row} Column={tile.Column}")
    {
        Tile = tile;
    }

    public Tile Tile { get; }
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
public class TileOccupiedException : Exception
{
    public TileOccupiedException()
    {
    }

    public Tile? Tile { get; set; }
}
\end{lstlisting}

\subsubsection{Regla: un rechazo cruza el contrato como falla tipada}

\textbf{Regla:} Una operación de servicio devuelve solo su resultado de éxito, y una operación sin resultado es \texttt{void}, nunca \texttt{bool}. Un rechazo no viaja como un código dentro de la respuesta: se declara con \texttt{[FaultContract]} y se envía como \texttt{FaultException<T>}, cuyo detalle es una clase de datos terminada en \texttt{Fault}. Los motivos parecidos se agrupan en una sola falla, con un enum que dice el motivo (Microsoft, 2017).

\textbf{Descripción:} La falla que declara el contrato es el mecanismo de WCF para el error, y el cliente la recibe como excepción; un código dentro de la respuesta, o un \texttt{bool} que no dice qué pasó, obliga al cliente a revisar cada respuesta y deja pasar en silencio el caso que olvide.

\textbf{Excepción:} Se conserva un enum de respuesta que distingue entre resultados de éxito y no entre rechazos, como el que dice si una solicitud de amistad se envió o si la amistad ya empezó. Una falla cuyo motivo no debe revelarse no se agrupa con las demás: la de credenciales inválidas no dice si la cuenta existe (Sección 9.3.2).

\textbf{Código correcto:}

\textit{Archivo \texttt{IRoomService.cs}:}
\begin{lstlisting}[style=csharpstyle]
[ServiceContract]
public interface IRoomService
{
    [OperationContract]
    [FaultContract(typeof(RoomRejectedFault))]
    JoinedRoom JoinRoom(string roomCode);

    [OperationContract]
    [FaultContract(typeof(RoomRejectedFault))]
    void LeaveRoom(string roomCode);
}
\end{lstlisting}

\textit{Archivo \texttt{RoomRejectedFault.cs}:}
\begin{lstlisting}[style=csharpstyle]
[DataContract]
public sealed class RoomRejectedFault
{
    [DataMember]
    public RoomRejectionReason Reason { get; set; }
}
\end{lstlisting}

\textit{Archivo \texttt{RoomRejectionReason.cs}:}
\begin{lstlisting}[style=csharpstyle]
public enum RoomRejectionReason
{
    RoomNotFound,
    RoomFull,
    PlayerBanned,
    NotInRoom,
}
\end{lstlisting}

\textbf{Código incorrecto:}

\textit{Archivo \texttt{IRoomService.cs}:}
\begin{lstlisting}[style=csharpstyle]
[ServiceContract]
public interface IRoomService
{
    [OperationContract]
    JoinAttempt JoinRoom(string roomCode);

    [OperationContract]
    bool LeaveRoom(string roomCode);
}
\end{lstlisting}

\textit{Archivo \texttt{JoinAttempt.cs}:}
\begin{lstlisting}[style=csharpstyle]
[DataContract]
public sealed class JoinAttempt
{
    [DataMember]
    public JoinAttemptCode Code { get; set; }

    [DataMember]
    public string? RoomCode { get; set; }
}
\end{lstlisting}

\textit{Archivo \texttt{JoinAttemptCode.cs}:}
\begin{lstlisting}[style=csharpstyle]
public enum JoinAttemptCode
{
    Joined,
    RoomNotFound,
    RoomFull,
    PlayerBanned,
}
\end{lstlisting}
