\subsection{Comentarios de Línea y de Bloque}

\subsubsection{Regla: preferir comentarios de línea breves}

\textbf{Regla:} Se usa un comentario de línea con \texttt{//} para una explicación breve y excepcional. Se evita el comentario de bloque \texttt{/* ... */}; si la explicación requiere varias líneas, se mejora el diseño o se traslada la explicación al documento técnico correspondiente. Ningún comentario conserva código deshabilitado (Microsoft, 2025e).

\textbf{Ejemplo correcto:} Una sola línea en inglés explica por qué se mantiene compatibilidad con una partida guardada por una versión anterior.

\textbf{Ejemplo incorrecto:} Un bloque extenso narra paso a paso el algoritmo, o conserva varias instrucciones deshabilitadas que deberían eliminarse del archivo.
