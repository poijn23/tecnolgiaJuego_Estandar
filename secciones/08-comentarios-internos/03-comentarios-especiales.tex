\subsection{Comentarios Especiales}

\subsubsection{Regla: \texttt{TODO} y \texttt{FIXME} solo en ramas de trabajo}

\textbf{Regla:} \texttt{TODO} identifica trabajo planificado y \texttt{FIXME} un defecto conocido que requiere corrección. Ambos se admiten únicamente en una rama de trabajo, se escriben en inglés, incluyen el identificador de una tarea y describen una acción concreta. Una solicitud de cambios enviada a revisión, y el código integrado a la rama principal, no contiene ningún \texttt{TODO} ni \texttt{FIXME}: antes de solicitar la revisión, el trabajo pendiente se completa o se registra como una tarea independiente en el sistema de seguimiento del equipo, y el comentario se retira del código.

\textbf{Código correcto (en una rama de trabajo, antes de solicitar la revisión):}
\begin{lstlisting}[style=csharpstyle]
// TODO(GAME-142): Replace the temporary save adapter.
private readonly ISaveAdapter _saveAdapter = new MemorySaveAdapter();
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
// TODO: Fix this later.
private readonly ISaveAdapter _saveAdapter = new MemorySaveAdapter();
\end{lstlisting}

\textbf{Ejemplo incorrecto:} La solicitud de cambios enviada a revisión conserva ``TODO(GAME-142): Replace the temporary save adapter.'' en lugar de resolverlo o registrarlo como tarea.
