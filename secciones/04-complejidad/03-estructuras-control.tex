\subsection{Estructuras de Control}

\subsubsection{Regla: llaves obligatorias en todo bloque}

\textbf{Regla:} Llaves \texttt{\{\}} obligatorias en toda estructura de control, incluso con una única instrucción; regla \texttt{IDE0011} (Microsoft, 2023e).

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
if (diceRoll == MaximumFaceValue)
{
    GrantExtraTurn();
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
if (diceRoll == MaximumFaceValue)
    GrantExtraTurn();
\end{lstlisting}

\subsubsection{Regla: rama \texttt{default} obligatoria en \texttt{switch}}

\textbf{Regla:} Todo \texttt{switch} incluye una rama \texttt{default} explícita para los valores no contemplados (McConnell, 2004). Prohibido devolver una cadena literal directamente en cada rama cuando el valor se reutiliza en más de un lugar: se declara como una constante con nombre descriptivo (o se centraliza en un diccionario indexado por el valor del enum) para que un error de tecleo en una de las repeticiones no introduzca una inconsistencia silenciosa.

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
private const string WaitingForRollLabel = "Waiting for roll";
private const string MovingLabel = "Moving";
private const string FinishedLabel = "Finished";

public string DescribeTurnState(TurnState state)
{
    switch (state)
    {
        case TurnState.WaitingForRoll:
            return WaitingForRollLabel;
        case TurnState.Moving:
            return MovingLabel;
        case TurnState.Finished:
            return FinishedLabel;
        default:
            throw new ArgumentOutOfRangeException(nameof(state), state, "Unsupported turn state.");
    }
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
public string DescribeTurnState(TurnState state)
{
    switch (state)
    {
        case TurnState.WaitingForRoll:
            return "Waiting for roll";
        case TurnState.Moving:
            return "Moving";
        case TurnState.Finished:
            return "Finished";
    }

    return string.Empty;
}
\end{lstlisting}
