\subsection{Niveles de Registro}

\subsubsection{Regla: elección del nivel según la severidad del evento}

\textbf{Regla:} Cada mensaje se registra mediante el método de log4net que corresponde a su severidad, de menor a mayor (Apache Software Foundation, s. f.-a):

\begin{itemize}
  \item \textbf{Debug}: información útil en desarrollo (resultado intermedio de un cálculo).
  \item \textbf{Info}: flujo normal del juego (inicio de partida, cambio de turno).
  \item \textbf{Warn}: anomalía que no impide continuar (movimiento inválido).
  \item \textbf{Error}: fallo que impide completar una operación, pero permite que el proceso continúe.
  \item \textbf{Fatal}: fallo irrecuperable que obliga a terminar la sesión o el proceso.
\end{itemize}

\textbf{Regla: excepción y severidad.} El objeto de excepción se adjunta como segundo parámetro de la llamada de registro únicamente en \texttt{Warn}, \texttt{Error} y \texttt{Fatal}, los niveles que se originan en un bloque \texttt{catch}; \texttt{Debug} e \texttt{Info} documentan flujo normal y no reciben una excepción. Toda excepción que se captura y se maneja sin volver a lanzarse se registra, como mínimo, en \texttt{Warn}. Cuando el \texttt{catch} solo traduce la excepción a otro tipo y la relanza (Sección 9.2), el registro ocurre en el punto donde finalmente se maneja, no en cada traducción intermedia. Una excepción que obliga a finalizar la sesión o el proceso completo --- no solo la operación en curso --- se registra en \texttt{Fatal}.

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class TurnManager
{
    public void StartTurn(Player player)
    {
        _logger.Info($"Turn started. Player={player.Name}.");
    }

    public void RejectMove(Player player, Tile destination)
    {
        _logger.Warn($"Move rejected. Player={player.Name}; Destination={destination}.");
    }

    public void AbortSession(GameSession session, Exception ex)
    {
        _logger.Fatal($"Session aborted. SessionId={session.Id}.", ex);
    }
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class TurnManager
{
    public void StartTurn(Player player)
    {
        _logger.Error($"Turn started. Player={player.Name}.");
    }

    public void RejectMove(Player player, Tile destination)
    {
        _logger.Error($"Move rejected. Player={player.Name}; Destination={destination}.");
    }

    public void AbortSession(GameSession session, Exception ex)
    {
        _logger.Debug($"Session aborted. SessionId={session.Id}.", ex);
    }
}
\end{lstlisting}
