\section{Documentación XML}

El uso de comentarios de documentación XML (\texttt{///}) está reservado a clases de alta importancia, contratos arquitectónicos (interfaces) y métodos cuya complejidad no sea evidente a partir de su firma. Queda prohibido documentar con \texttt{///} miembros autoexplicativos, como propiedades automáticas o métodos que sobrescriben una interfaz con \texttt{override}.
