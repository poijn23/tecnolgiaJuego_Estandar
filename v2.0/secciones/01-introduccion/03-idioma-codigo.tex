\subsubsection{Regla: identificadores en inglés}

\textbf{Regla:} Todo identificador (clases, interfaces, métodos, variables, constantes, espacios de nombres, mensajes de excepción) se escribe en inglés. Los comentarios de justificación de negocio pueden redactarse en español (Microsoft, 2025c).

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
public int CalculatePlayerScore(Player player)
{
    return player.BaseScore + player.BonusScore;
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
public int calcularPlayerScore(Player jugador)
{
    return jugador.BaseScore + jugador.BonusScore;
}
\end{lstlisting}
