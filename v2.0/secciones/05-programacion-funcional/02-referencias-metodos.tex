\subsection{Referencias a Métodos}

\subsubsection{Regla: grupo de método sobre lambda de reenvío}

\textbf{Regla:} Cuando una expresión lambda se limite a reenviar sus argumentos directamente a otro método existente, deberá preferirse la conversión de grupo de métodos (usar el nombre del método directamente) sobre la lambda equivalente.

\textbf{Descripción:} Esta preferencia produce un código más declarativo y más sencillo de depurar. La documentación de C\# indica que un objeto delegado se puede construir proporcionando directamente el nombre del método que envuelve, como alternativa a una expresión lambda (Microsoft, 2024).

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
_players.ForEach(RegisterPlayerScore);
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
_players.ForEach(player => RegisterPlayerScore(player));
\end{lstlisting}
