\subsection{Nomenclatura de las Clases de Prueba}

\subsubsection{Regla: sufijo \texttt{Tests}}

\textbf{Regla:} Una clase de prueba se nombra igual que la clase examinada, con el sufijo \texttt{Tests} en plural (Osherove, 2013).

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class DiceRollerTests
{
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class TestDiceRoller
{
}
\end{lstlisting}
