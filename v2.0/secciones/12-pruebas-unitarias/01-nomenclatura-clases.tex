\subsection{Nomenclatura de las Clases de Prueba}

\subsubsection{Regla: sufijo \texttt{Tests}}

\textbf{Regla:} Toda clase de prueba deberá nombrarse igual que la clase que examina, seguido del sufijo \texttt{Tests} en plural.

\textbf{Descripción:} Osherove señala que el nombre de una clase de prueba debe permitir identificar de inmediato, sin abrir el archivo, qué unidad de producción examina, de manera que localizar las pruebas de una clase sea inmediato para cualquier integrante del equipo (Osherove, 2013).

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class DiceRollerTests
{
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
public sealed class TestDiceRoller
{
}
\end{lstlisting}
