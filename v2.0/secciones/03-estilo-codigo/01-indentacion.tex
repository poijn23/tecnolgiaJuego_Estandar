\subsection{Indentación}

\subsubsection{Regla: cuatro espacios por nivel}

\textbf{Regla:} Cada nivel de indentación usa exactamente cuatro espacios; prohibido el carácter de tabulación (Microsoft, 2025e).

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
public int RollDice()
{
    int faceValue = Random.Shared.Next(1, 7);

    if (faceValue == 6)
    {
        return faceValue + BonusRoll();
    }

    return faceValue;
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
public int RollDice()
{
  int faceValue = Random.Shared.Next(1, 7);

  if (faceValue == 6)
  {
      return faceValue + BonusRoll();
  }

  return faceValue;
}
\end{lstlisting}
