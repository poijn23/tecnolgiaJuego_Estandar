\subsection{Restricciones}

\subsubsection{Regla: prohibido \texttt{Console.WriteLine} como bitácora}

\textbf{Regla:} Prohibido \texttt{Console.WriteLine}, \texttt{Console.Error.WriteLine} o \texttt{Debug.Print} para registrar eventos del juego; todo registro pasa por el colaborador de registro del proyecto (McConnell, 2004).

\textbf{Código correcto:}
\begin{lstlisting}[style=csharpstyle]
public void SaveGameState(GameState state)
{
    try
    {
        _repository.Save(state);
    }
    catch (IOException ex)
    {
        _logger.Error($"Failed to save game state for session {state.SessionId}: {ex.Message}");
    }
}
\end{lstlisting}

\textbf{Código incorrecto:}
\begin{lstlisting}[style=csharpstyle]
public void SaveGameState(GameState state)
{
    try
    {
        _repository.Save(state);
    }
    catch (IOException ex)
    {
        Console.WriteLine("Failed to save game state: " + ex.Message);
    }
}
\end{lstlisting}
